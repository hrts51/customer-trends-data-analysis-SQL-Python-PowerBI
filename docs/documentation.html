🔍 Key Business Insights
1
Gender Revenue Gap is Smaller Than Expected — Male customers are 68% of transactions but their per-transaction spend is only marginally higher than female customers.
2
Clothing Dominates, Spring Peaks — Clothing is the top revenue category across all seasons. Spring drives the highest seasonal revenue.
3
Subscriptions Drive Loyalty — Subscribed customers spend more per transaction and have significantly more previous purchases than non-subscribers.
4
Champions Are the Revenue Core — The top RFM segment is ~20% of customers but drives a disproportionately large share of total revenue.
5
Churn Profile is Clear and Actionable — At-risk customers are identifiable: infrequent buyers, low review ratings, not subscribed.
6
Discounts Don't Always Lift Spend — Discount buyers don't consistently spend more than non-discount buyers on average — discount strategy needs review.

🚀 Quick Start
# 1. Clone the repo
git clone https://github.com/hrts51/customer-trends-data-analysis-SQL-Python-PowerBI.git
cd customer-trends-data-analysis-SQL-Python-PowerBI

# 2. Set up environment (Conda recommended)
conda create -n customer-analysis python=3.13
conda activate customer-analysis
pip install -r requirements.txt

# 3. Run the notebook
jupyter notebook Customer_Shopping_Behavior_Analysis.ipynb

# 4. Load data to SQL — uncomment the relevant DB section in the notebook

# 5. Open Power BI — connect to SQL DB or the cleaned CSV
